# Cole — сайт для учёбы

Статический сайт (без сервера и сборки) на GitHub Pages: https://do2agency.github.io/cole/
Репозиторий: https://github.com/do2agency/cole. Любой push в `main` публикуется за 1–2 минуты.
Владелица — Наталья, общаемся по-русски. Она не программирует: объясняй просто и показывай результат.

## Что это
Тренажёр для ребёнка по школьному модулю (≈3 месяца): английский, испанский (Lengua), валенсийский.
Структура как в школьной платформе Toddle: Предмет → Триместр → Vocabulario / Gramática → темы-игры.

## Файлы
- `index.html` — «Plan del curso»: меню предметов слева (на телефоне — вкладки), темы с отметками ⚪🟡✅⭐.
- `juego.html?t=<id>` — игра по теме. Одна страница на все темы.
- `temas.js` — **весь контент**. Новая тема = новый блок в `TEMAS`:
  - `tipo: "conj"` — спряжения: `pronombres`, `tiempos` (`cuando`, `nombre`, `formas` по порядку местоимений), `acentos` — кнопки букв с ударением.
  - `tipo: "vocab"` — слова: `items: [["вопрос", "ответ"], ...]`. Для тестов можно третьим элементом дать неверные варианты: `["вопрос", "ответ", ["неверн1", "неверн2", "неверн3"]]` (True/False — `...TF` / `...FT`).
  - `tipo: "mult"` — таблица умножения: `tablas` (какие таблицы), `por` (множители, сейчас ×2…×9 — без ×1 и ×10), `elegir: true` — галочки «¿Qué tablas?», любая комбинация (тема «Mezcla»). Когда отмечены все, первое касание оставляет только эту таблицу, дальше касания добавляют/убирают.
  - Новый предмет или триместр — в `MATERIAS`. У предмета можно задать свои `secciones` (у Matemáticas — `calc` «Cálculo») и `premio`: `"coches"` — только машины, `"mezcla"` — футболисты и машины по очереди (сейчас у Matemáticas), или список групп по очереди, напр. `["jugadores", "coches"]`. У Natural Science — `"mezcla"` (сквиши 18.10 убраны по просьбе Натальи: рисунки «не сквиши»).
  - Ответ с вариантами через « / » (напр. «undécimo / decimoprimero») — в Escribir засчитывается любой; «15 cuadraditos»/«6 cm» — можно написать только число.
  - `tipo: "reloj"` — часы со стрелками (SVG рисуется в juego.html), ответ — время словами по-английски (o'clock / quarter past / half past / quarter to); `horas: [1…12]`. Тема English «Telling the time».
  - English: «Vocabulary 1.2» и «WH- question words» — предложение с пропуском «…» + 4 варианта (формат, который просила Наталья). В WH-вопросах после «—» дан ответ, чтобы вариант был однозначным.
  - Matemáticas, раздел `test`: Perímetro y área, Círculo y circunferencia, Los números ordinales (по тетради ребёнка).
  - Natural Science (Cambridge Natural Science 3): Unit 1 — объект `NS1` в temas.js (тесты по урокам + Review из всех), раздел `test` «Tests».
- `jugadores.js` + `img/j/` — фото футболистов сборной Испании (Wikimedia Commons, CC BY-SA 4.0).
- `coches.js` + `img/c/` — фото спорткаров, награда в Matemáticas вперемешку с футболистами (Wikimedia Commons).
- `creditos.html` — авторы фото. Новое фото = новая строка с автором и лицензией.
- `estilo.css` — общие цвета и шрифты (красный/жёлтый сборной, светлая и тёмная тема).
- `manifest.webmanifest`, `img/icono-*.png` — иконка «COLE» для рабочего стола телефона.

## Договорённости с Натальей (важно)
- **На сайте ничего по-русски.** Все надписи и сообщения на испанском; сами слова и формы — на языке предмета (валенсийские формы как в учебнике).
- Игра: режим по умолчанию **Elegir** (1 из 4), переключение на **Escribir** крупными плитками «¿Cómo quieres jugar?». Ударения в Escribir обязательны (подсказка «¡Casi! Revisa el acento.»).
- Ошибка не засчитывается: карточка уходит в конец с пометкой «↻ Otra vez», игра идёт, пока на каждую не ответят верно. Верный ответ — «¡GOL!» и фото игрока; каждый 4-й гол — всегда Lamine Yamal (просьба Натальи 12.10).
- **Сайт публичный:** никаких имён ребёнка, названия школы, класса, фото тетрадей и других личных данных.
- Переводы проверять, ничего не выдумывать; сомнительное — сказать Наталье.
- Перед правками — `git pull`: сайт также правит агент Натальи в Telegram.
- **Кэш:** скрипты и CSS подключены с `?v=ДАТА` (в index.html, juego.html, creditos.html). После правок temas.js / *.js / estilo.css поменять `?v=` везде, иначе на телефоне (ярлык на рабочем столе) остаётся старая версия.
